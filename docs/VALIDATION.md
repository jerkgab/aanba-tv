Дата: 27 октября 2026 года. Это проверка конкретной сборки, не сертификат безопасности и не гарантия совместимости со всеми телевизорами.

Проверены парсеры AANBA/ESPN/YouTube, даты будущих матчей, несовпадение повторных встреч, исторические сезоны, нулевые броски, eFG/TS, избранные, сохранение и восстановление позиции **реального локального диагностического MP4**, шкала/пульт/двойной Back, непрерывность видео рядом с панелью, таблица/календарь/box score, безопасные URL и отказ YouTube без исчезновения раздела.

Отдельно десять одновременных подписчиков одной загрузки получили данные после одного сетевого запроса. Затем имитирован отказ источника и подтверждена выдача сохранённого кэша. Это тест объединения запросов внутри одного приложения, а не нагрузочная проверка десяти физических телевизоров и не обещание лимитов ESPN/VK/YouTube.

Каждая установка обращается к источникам самостоятельно. Общего сервера приложения нет, поэтому зрители не нагружают устройство, интернет или сервер автора.

## Аппаратная граница

В предыдущей 1.3 на физическом Android TV проверялись настоящая публичная запись VK, выбор качества стрелками/OK, перемотка и видео рядом со статистикой. 1.4 установлена и её главная проверялась на физическом ТВ. При подготовке 1.4.1 этот ТВ был недоступен по сети.

В 1.4.1 **VK на эмуляторе не подтвердил готовность видео за время проверки**. Это не выдаётся за успешный реальный просмотр. Продолжение именно VK-записи в 1.4.1, live/DVR, длительные сеансы и физические повторы пультов разных моделей остаются за пределами подтверждённого результата. Для первых пользователей версия отмечена как тестовая; необходим доступ к источникам и исправный актуальный WebView.

## Самостоятельные проверки

```sh
python3 scripts/audit_public.py
./gradlew testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
adb -s emulator-5554 install -r app/build/outputs/apk/debug/app-debug.apk
adb -s emulator-5554 install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -s emulator-5554 shell am instrument -w -r \
  -e class pro.aanba.tv.PlayerTest,pro.aanba.tv.HomeUiTest,pro.aanba.tv.BasketballUiTest,pro.aanba.tv.SourceTest,pro.aanba.tv.PolishUiTest,pro.aanba.tv.PublicReadinessTest \
  pro.aanba.tv.test/android.test.InstrumentationTestRunner
```

Всегда выбирайте тестовое устройство явно. Не запускайте общий `connectedDebugAndroidTest`, если подключён личный ТВ: инструментальные тесты меняют состояние приложения. `VkPlayerTvTest` — отдельный сознательный запуск с настоящим публичным VK на выбранном устройстве; доступность конкретной записи и качества зависит от источника. `PublicScreenshotsTest` отдельно получает реальные публичные данные для снимков интерфейса.

Скрипт audit_public.py ищет распространённые шаблоны секретов/личных путей и адресов, проверяет имена файлов и разрешения. Он помогает не опубликовать лишнее, но не заменяет полный независимый аудит.

## Структура публикации

В репозитории только AANBA TV: код, публичные тестовые данные, документация, скриншоты и APK. Личные журналы разработки/установки, чужие проекты, настройки оборудования, ключи подписи и пользовательские настройки в публикацию не входят. В release APK тестовые JSON и длинное диагностическое видео для тестов не включены; короткий цветовой тест экрана доступен через справку приложения.
