# Установка и управление

1. Скачайте APK по ссылке в README.
2. Передайте его на Android TV / Google TV любым привычным способом (флешка, локальная передача файлов, ADB).
3. Откройте APK и разрешите установку из этого источника, если Android запросит. Режим разработчика для установки через файловый менеджер не нужен.
4. Запустите AANBA TV из списка приложений. Пароли и API-ключи вводить не нужно.

Для ADB используйте адрес **своего** устройства:

```sh
adb connect YOUR_TV_ADDRESS:5555
adb -s YOUR_TV_ADDRESS:5555 install -r downloads/AANBA-TV-1.4.1.apk
```

В репозитории нет адреса или ключей доступа к телевизору автора. Android 8.0 — минимальная версия. Если WebView выключен или устарел, включите/обновите Android System WebView в настройках/магазине своего устройства.

| Действие | Пульт |
|---|---|
| Выбрать матч / кнопку | Стрелки, OK |
| Открыть / закрыть правую статистику | Удерживать ↑ от 0,55 с |
| Команды / игроки в статистике | Короткие ← / → |
| Прокрутка статистики | Короткие ↑ / ↓ |
| Показать шкалу записи | Короткое ↑ или ← / → |
| Перемотка | ← / →; удержание ускоряет, отпускание применяет |
| Кнопки плеера | ↓, затем ← / → и OK |
| С начала записи | Круговая стрелка рядом с паузой |
| Качество | Шестерёнка → Качество → Другое → вариант VK → OK |
| Скрыть интерфейс | Один Назад |
| Вернуться к матчам | Два быстрых Назад до 1,2 с |

История записи сохраняется примерно каждые пять секунд и при выходе. У короткого фрагмента до 15 секунд нет подписи «Продолжить». Последние до 30 секунд считаются досмотренной записью. Для live без DVR перемотки нет.

YouTube: «Обновить» повторяет загрузку ленты, «Канал» открывает AANBA в установленном YouTube / SmartTube. При сбое сети показывается сохранённая подборка с соответствующей подписью. Нажатие ролика не гарантирует, что YouTube доступен в сети устройства.
